# chupchoet.camera

## Overview

chupchoet.camera is a camera marketplace for browsing listings, publishing cameras for sale, and submitting purchase orders. Rental periods, booking calendars, and scheduling workflows are not part of the product.

Pickup date and time can be provided as optional order details to coordinate handoff; they never represent a rental period.

## Local development

```bash
npm install
npm run dev
```

The public marketplace is available at `/booking` (and `/` redirects there). Admins can sign in at `/admin/khanh` to manage listings and purchase orders.
